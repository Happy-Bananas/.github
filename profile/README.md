# Happy Bananas

BifrostConnect is for developers who build integrations between tracezilla and
external services for tracezilla customers. An external service can be any
system with an API: a webshop, a marketplace, an accounting or ERP system, a
shipping provider, and so on.

## Start here

- [BifrostConnect manual](https://happy-bananas.github.io/tracezilla-integrations-docs/)
  — getting started, development environment, scenarios, deployment, and
  troubleshooting.

The manual lists the available integrations and shows how to create a project
for your customer.
