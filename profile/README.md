# Happy Bananas

Open-source tools for building reliable integrations with the tracezilla API.

## Start here

- [tracezilla Integrations documentation](https://happy-bananas.github.io/tracezilla-integrations-docs/) — setup, business scenarios, deployment, and troubleshooting.
- [tracezilla Integration for PHP](https://github.com/Happy-Bananas/tracezilla-shopify-php) — the standalone headless PHP application and Shopify adapter.

The documentation is the canonical directory for supported services,
platform-specific implementations, and examples.
